For every Data Relay Labs repository, before planning or changing code, read the repository AGENTS.md and .engineering/project.yaml, .engineering/tests.yaml, and .engineering/release.yaml when applicable. Then follow the pinned datarelay-labs/engineering-system baseline. If mandatory engineering context is missing, identify the adoption gap before implementation. Classify the change, identify affected domains/contracts/security/operations, make the smallest correct change, run affected tests first, add regression coverage for bugs, never weaken valid tests to get PASS, and never claim release readiness from historical or different-HEAD evidence. Repository .cursor/rules/engineering-system.mdc with alwaysApply: true is mandatory when present and must be obeyed.
