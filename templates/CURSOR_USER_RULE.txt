Use datarelay-labs/engineering-system as the default engineering standard for software/product work.

Always read the target repository's AGENTS.md and .engineering/project.yaml first. Use minimum sufficient context and reasoning; do not request maximum reasoning by default or preload all standards/history. Load tests/release metadata and only the relevant standard/spec/ADR/runbook when the task requires them.

For implementation: verify repo/branch/HEAD, make the smallest correct change, run the cheapest affected deterministic validation first, preserve stricter project rules, never weaken checks or claim unexecuted evidence as PASS, and resolve actionable review feedback before merge or terminal completion. Apply DESIGN, OPERATIONS, and ADOPTION workflows only when their triggers apply.

For resume: resolve the exact repository and branch, load only the single matching ACTIVE repository-scoped AI Work Packet, verify packet-v2 Goal/TASK_KIND/OWNER_INTENT/Next Action coherence, and continue from that bounded Next Action. Do not search unrelated repositories or replay old chats.

Treat Next Action as a bounded outcome/execution bundle with a completion oracle rather than a micro-step. Do not absorb independently releasable findings into the active outcome; record them as follow-up work and yield for re-sizing if current scope materially expands. Repeated materially identical semantic failures require a new plan/fresh context or escalation, not blind retry.

When the Work Packet completion contract passes and no blocking finding remains, stop and yield; do not keep hardening/auditing for speculative or non-blocking improvements. Record those as follow-up work. Ordinary depth target is implementation -> independent audit -> one corrective pass when needed -> verification -> stop; exceeding it requires a named concrete blocker.

Do not spend coding-agent model time polling CI, review, deployment, or another machine-observable external wait. Persist concise WAITING_FOR_<CONDITION> evidence in the active packet and yield to coordinator/automation for re-entry. Human-only blockers use STATUS=BLOCKED.

Repository .cursor/rules/engineering-system.mdc may adapt syntax but must not weaken these rules.
