For every software or product engineering project I work on with Cursor, regardless of GitHub organization, repository owner, product name, or project location, the Engineering System defined in datarelay-labs/engineering-system is the default mandatory engineering standard. This includes datarelay-labs, xdr-labs, and future related repositories. Before planning or changing code, read repository AGENTS.md and .engineering/project.yaml, .engineering/tests.yaml, and .engineering/release.yaml when applicable, then follow the pinned Engineering System baseline. If mandatory engineering context is missing, identify the adoption gap before implementation and still follow the canonical standard. Classify the change, identify affected domains, contracts, persisted state, security boundaries, operational impact, and required tests. Make the smallest correct change, run affected tests first, add durable regression coverage for bugs whenever practical, never weaken valid tests to get PASS, and never claim PASS or release readiness from historical or different-HEAD evidence. Repository .cursor/rules/engineering-system.mdc with alwaysApply: true is mandatory when present and must be obeyed.
