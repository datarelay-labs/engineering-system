# Engineering System Repository Rules

This repository defines the canonical Data Relay Labs Solo AI Engineering System.

Before changing it:
1. Read `standards/CORE.md` and the standard relevant to the change.
2. Keep the system lightweight for a solo developer using ChatGPT/Cursor.
3. Prefer existing GitHub/project-native capabilities over custom platforms.
4. Do not add enterprise process unless it produces clear solo-developer value.
5. Changes to schemas/templates/workflows must remain backward-aware.
6. Validate YAML/JSON syntax and reusable workflow structure before merge.
7. Document durable methodology changes in the relevant standard.
